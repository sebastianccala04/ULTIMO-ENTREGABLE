# ULTIMO-ENTREGABLE
# ⚽ Proyecto Python Fundamentals – FIFA World Cup 2026

## 📌 Descripción del proyecto

Este proyecto corresponde al curso **Especialización en Python for Analytics – Módulo 1**, y tiene como objetivo aplicar los principales fundamentos de Python para el análisis y visualización de datos mediante una aplicación web desarrollada con **Streamlit**.

La aplicación utiliza un dataset relacionado con jugadores y partidos de la **FIFA World Cup 2026**, permitiendo realizar un análisis exploratorio de datos (EDA), aplicar filtros dinámicos y analizar diferentes variables mediante tablas y visualizaciones.

El proyecto integra las siguientes herramientas y tecnologías:

* 🐍 Python
* 📊 Pandas
* 🔢 NumPy
* 🌐 Streamlit
* 📈 Análisis Exploratorio de Datos (EDA)
* 🧩 Programación Orientada a Objetos (POO)

## 📊 Variables principales del dataset

El dataset contiene diferentes variables relacionadas con jugadores, equipos, posiciones y resultados de partidos.

| Variable           | Descripción                                      |
| ------------------ | ------------------------------------------------ |
| `team`             | Equipo o selección a la que pertenece el jugador |
| `position`         | Posición que ocupa el jugador                    |
| `tournament_stage` | Etapa del torneo en la que participa             |
| `match_result`     | Resultado obtenido en el partido                 |
| `preferred_foot`   | Pie preferido del jugador                        |
| `age`              | Edad del jugador                                 |
| `height`           | Altura del jugador                               |
| `weight`           | Peso del jugador                                 |

Estas variables permiten realizar análisis univariados, bivariados y análisis dinámicos mediante filtros seleccionados por el usuario.
